# WoWs Info Android shell

Jetpack Compose app that talks to the shared Rust core (`../core`) through the
generated BoltFFI bridge. The core handles search, player stats and rating
calculation; the shell only provides HTTP, key-value storage, time and UI.

## Layout

- `shared/` – Android library that compiles the generated Kotlin bindings and
  packages the native `libwowsinfo_core.so` for all four ABIs.
- `app/src/main/java/com/wowsinfo/libwowsinfo/` – the shell:
  - `core/` – `Core` (FFI + effect loop), HTTP/KV/time handlers.
  - `ui/` – search screen, player stats screen, formatting helpers.
- `generated/` – generated by BoltFFI/typegen; gitignored and not hand-edited.

## Build

Prerequisites: Android SDK/NDK, the four Rust Android targets, and the BoltFFI
CLI (`cargo install boltffi_cli --version 0.29.3 --locked`).

```sh
# 1. Regenerate types and native libraries (from core/)
cd ../core
boltffi pack android

# 2. Build the APK (from android/)
cd ../android
./gradlew :app:assembleDebug
```

## API key

The Wargaming API key is embedded in the Rust core at build time. Put it in
`keys.toml` at the repo root (`app_key = "..."`) or set `WOWSINFO_APP_KEY`,
then re-run `boltffi pack android` and rebuild the APK. Without a key the app
starts but shows a "Missing Wargaming API key" error.

## Run on a device

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.wowsinfo.libwowsinfo/.MainActivity
```
